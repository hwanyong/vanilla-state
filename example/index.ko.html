상태 업데이트는 반응적이며 즉각적입니다.

압도적인 단순함

복잡한 보일러플레이트 없는 반응형 상태. 객체를 래핑하고 변화를 구독하기만 하세요.

const count = new VnlState(0);

count.addEventListener('change', (val) => {
  el.innerText = val;
});

// 값을 업데이트하면 즉시 반영됩니다!
count.set(count + 1);

🚀 초경량 설계

의존성 제로. 압축 시 2KB 미만의 매우 작은 크기. 성능을 최우선으로 생각합니다.

🔄 프록시 기반

네이티브 ES6 Proxy를 사용하여 효율적인 변화 감지를 수행합니다. 가상 돔 없이 즉각 반응합니다.

🎯 프레임워크 독립적

React, Vue, Angular 또는 순수 Vanilla JS 프로젝트 어디서든 완벽하게 통합됩니다.
